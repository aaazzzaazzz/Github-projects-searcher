## 使用说明

### 映射优先级

1. **级别映射优先**：如果查询中包含具体的级别描述（如"高活跃度"），优先使用级别映射
2. **通用关键词次之**：如果没有级别映射，则使用通用关键词映射
3. **编程语言映射**：独立处理，不与其他映射冲突

### 匹配规则

- 使用**包含匹配**而非精确匹配，例如"高活跃度"可以匹配"这个项目高活跃度"
- 匹配时忽略大小写
- 支持部分匹配，例如"活跃"可以匹配"活跃项目"
